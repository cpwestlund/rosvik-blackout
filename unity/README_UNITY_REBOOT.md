# ROSVIK: BLACKOUT — Unity Reboot

This is a clean reboot, not a Godot port.

## Vertical-slice acceptance target
One authored location only:
1. Rosviks skola exterior and recognisable entrance.
2. Snowy schoolyard with deliberate prop placement.
3. Player walks through the physical entrance without teleporting.
4. Corridor and one classroom are real connected spaces.
5. W/S/A/D are world-locked and never change when the camera rotates.
6. Middle-mouse orbit is non-inverted; wheel zooms.
7. Cozy-apocalyptic blackout lighting: cold exterior, warm protected pockets.
8. No procedural duplicate props, floating objects, fake football fields, or decorative collision blockers.
9. Art direction: Project Zomboid readability + materially richer, handcrafted diorama detail.

## Rule
Do not expand Rosvik until this slice looks and feels like the target game.
