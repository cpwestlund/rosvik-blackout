# Rosvik Blackout – locked direction

## What must be true
- The game takes place in Rosvik.
- Roads, building footprints, school/sports area, football pitches and major landmarks use real map geography wherever public map data is available.
- Important names are shown in-game.
- Geography and recognition matter more than architectural replication.

## Visual target
- Stylized top-down illustrated game world.
- Late autumn / early spring: damp ground, wet roads, puddles, tired grass, dense northern vegetation and only occasional remaining snow.
- Strong silhouettes and readable colors rather than fake photorealism.
- Landmark buildings get distinctive colors/shapes, but there is no requirement to reproduce every facade, window or roof detail.

## Technical rule
The map data is invisible scaffolding. It decides WHERE things are, not HOW they must look.

Do not return to the stacked V10–V17 3D-prototype workflow. Do not spend iterations repairing procedural roofs, snow banks or decorative primitives. V18 and later should remain one authoritative scene generation path.

## Expansion order
1. Correct Rosvik geography.
2. Make the school/Rosvalla/arena area a polished playable top-down slice.
3. Expand along the real road network with houses, vegetation and named places.
4. Add survival/apocalypse systems and atmosphere only after the world reads well as Rosvik.
