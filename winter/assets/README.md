# Inventory artwork

loot_atlas.webp is a single 6-column, 3-row atlas generated with the built-in
image-generation tool for this project, then encoded as WebP without resizing.
The order is defined by ItemArt.IDS. The generated texture is 1774 x 887 pixels;
AtlasTexture regions use the actual dimensions, not an assumed 256-pixel grid.

Prompt specification: realistic, slightly worn Swedish household/workshop
supplies in consistent three-quarter product photography, soft upper-left
lighting, uniform dark slate background, no text/logos/grid. Six columns and
three rows, centered isolated objects, no overlap. Row 1: gloves, duct tape,
blue screwdriver, red pliers, cheap white Europlug USB charger, USB-C cable.
Row 2: water bottle, crispbread, jumper cables, headlamp, AA battery, towing rope.
Row 3: motor oil, socket kit, grey wool blanket, matches, steel thermos, first aid.
No fantasy or cartoon styling. Each tile is displayed separately in inventory.

Illustrative appearance is independent of a particular stack's condition.
Remaining unplaced catalog entries await future artwork.
